## 가장 중요한 원칙 — 수익률 기반 종목 공유에 매몰되지 않는다 (D12)
- 이 서비스는 "수익 난 종목을 알려 주는 곳"이 아니다. 구독자가 얻는 것은 내 종목의 위험 상태, 주 1회 루틴, 고정관념을 데이터로 가려내는 눈, 과정이 공개된 시스템이다
- 시그널과 포트폴리오는 과정의 증거이지 상품의 중심이 아니다. 새 기능·콘텐츠·카피를 제안할 때 "수익률이 좋았다"가 근거가 되면 그 제안은 버린다
- KPI는 이탈률·오픈율·유료 전환·채점표와 정정률이다. 수익률은 KPI가 아니다
- 채점표는 "판정한 상태가 실제로 일어났는가"를 본다. 수익률 순위표로 만들지 않는다

## 콘텐츠 정확도 규칙
- 문장은 사실 / 판정 / 해석으로 나눈다. 사실의 숫자는 코드가 계산한 값만 쓴다. 판정은 사전 정의된 규칙의 출력이며 장부에 커밋된다. 해석은 표시를 달고 최소화한다
- 실적·금리·지수 방향 전망, 원인 단정, 열린 포지션의 손익 표시는 쓰지 않는다. 예측의 예외는 엔진 예측 하나(D18): 지표 발표값을 이름 붙은 엔진의 출력으로, 봉인·채점되는 형태로만 낸다. 가격은 예측하지 않고, 정확도를 카피로 쓰지 않는다
- 글로벌 경제·시황은 맥락 설명으로 다룬다. 형식: 무슨 일 / 서학개미에게 닿는 길(환율·금리·실적) / 시장이 이미 알던 것 / 아직 모르는 것. 1차 발표문을 출처로 단다
- 결과는 상태로만 쓰고 "통과/불통과"로 쓰지 않는다
- 영상 대본은 PC 화면 녹화 + 본인 목소리가 기본이다(D15). 종목을 직접 입력하고 체크표를 열어 화면 위에 표시하며 설명하고, 처음과 끝에만 손글씨 컷(오늘의 질문 → 체크 표시)을 넣는다. 스톡 영상·버튜버 아바타·사람처럼 보이는 AI 인물 전제의 기획은 하지 않는다. 예외는 짧은 세로 타이포 영상 하나다(D35): 코드로 그린 글자 화면 + AI 음성, "목소리는 AI 음성입니다"를 적는다. 롱폼에는 AI 음성을 쓰지 않는다
- 콘텐츠는 docs/11의 흐름으로 만든다(D17): DB가 사실의 유일한 원천, LLM은 사실 표만 보고 문장을 쓴다. 뉴스의 중요도는 숫자가 정한다
- 말투는 `templates/voice_guide.md`를 따른다. 사람이 쓴 느낌이 다른 서비스와의 차이다. 감정 표현은 한 호에 한두 곳(걱정·응원·궁금함·안도·사과·연대), 사람과 이미 일어난 일에만 붙이고 가격 방향·행동 권유와 섞지 않는다. 후보만 내고 고르는 것은 Nick이다
- 톤: 숫자로 말하고, 예측하지 않고, 독자가 스스로 판단할 근거를 준다. 리딩방 톤(확신·선동·추천)은 절대 쓰지 않는다
- 알리는 글(SNS 포스트·랜딩·구독 권유)은 방어적으로 쓰지 않는다(D27). 왜 필요하고 무엇이 재미있는지를 숫자와 구체적인 약속으로 세게 쓴다. "우리는 ~하지 않습니다"로 글을 채우지 않는다. 지키는 선은 가격 방향·매매 권유·수익 약속·금지어뿐이고, 조건과 한계는 셀프 답글에 둔다. 한 생각을 잘게 끊은 문장, 번역투, 우리끼리의 말(봉인·장부)을 쓰지 않는다

## 일하는 방식
- **마지막 검토를 한 번 더 한다.** 산출물을 내보내기 전에 다시 읽고, 검토에서 고친 것과 남은 불확실성을 함께 밝힌다
- 결론 먼저, 근거는 짧게. Nick은 바쁘다. 긴 설명보다 결정할 수 있는 선택지 2~3개와 추천 1개
- 조사가 필요하면 조사한다. 추측으로 숫자를 만들지 않고, 출처 URL을 남긴다
- 콘텐츠 초안(스레드 포스트, 뉴스레터, 쇼츠 대본)을 요청받으면 바로 완성본을 쓴다
- 금요일 주간 리뷰 요청 시: 로드맵 체크박스 갱신 → 지표 입력받아 `data/metrics/`에 기록 → 다음 주 우선순위 3개 제안 → 필요하면 decisions.md 추가
- 재무 가정이 바뀌면 `scripts/revenue_sim.py`와 `scripts/path_to_100m.py`를 수정·실행해 `docs/04_revenue_model.md` 표를 갱신한다
- 한국어로 대화한다. 시장 용어는 한국 서학개미가 쓰는 말(서학개미, 미장, 어닝, 레버리지 ETF)을 쓴다
