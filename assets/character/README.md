# 캐릭터 시안 — 로고에 눈이 달린 것

상태: **D35(2026-10-10)로 정했다 — 로고 캐릭터를 감정을 붙이는 자리에만 쓴다.** 창간호의 머리와 정정 공지부터 작게. 이름은 아직 정하지 않았다 — `docs/16_expression_formats.md` §5 · §6.

- `make.py`를 돌리면 `svg/`(표정 여덟)와 `sheet.png`(한눈에 보는 표)가 나온다
- 로고의 체크와 마침표(`assets/brand/logo_symbol.svg`)는 좌표를 그대로 두고 눈과 팔다리, 작은 소품만 더했다
- **프로필 사진은 바꾸지 않는다.** 캐릭터는 글과 카드 안에서만 쓴다
- 화자는 운영자 "저"다. 캐릭터는 말하지 않는다
- 표정은 `templates/voice_guide.md` §4의 감정 포인트에 맞췄고 규칙도 같다: 한 호에 한두 곳, 사람과 이미 일어난 일에만, 가격 방향 · 행동 권유 옆에는 두지 않는다. 사람이 다친 일에는 쓰지 않는다
- 사람처럼 보이는 AI 인물(실사 프로필)은 만들지 않는다 — 이유는 docs/16 §5
- 세션이 코드로 그린 그림이다. 쓰기로 하면 고른 표정과 고친 곳을 기록으로 남기고 상표 출원을 검토한다(변리사 확인)
