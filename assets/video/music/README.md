# 유튜브에 얹을 음악

- **유튜브 스튜디오 → 오디오 보관함**에서 Nick이 듣고 고른 곡만 둔다(D38). 세션은 소리를 들을 수 없고 그 사이트에 닿지 못한다
- 유튜브에 올리는 파일에만 얹는다(`render.py --audio`). 스레드 · X · 인스타에 올리는 파일은 소리가 없다
- 곡을 넣을 때 아래 표에 한 줄 적는다. "저작자 표시 필요"로 나오는 곡은 영상 설명란에 적어야 하므로 표시가 필요 없는 곡을 고르는 편이 손이 덜 든다
