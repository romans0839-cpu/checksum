작성 2026-10-04. 개인 계정과 완전히 분리된 "브랜드 계정" 세트를 만든다. 총 40~50분.

## 0. 도메인 + Google Workspace (20분) — 모든 것의 뿌리
(D9: 무료 Gmail 대신 자체 도메인 메일. 이유: 뉴스레터 발신 도메인 인증(SPF/DKIM/DMARC) 필수, 스티비 발신자 @gmail.com은 스팸 위험)
1. 가비아 또는 호스팅kr에서 `checksumlab.com` 구매 (연 1.5~2만원). `checksum.kr` 비어 있으면 함께
2. workspace.google.com → 시작하기 → Business Starter → "이미 도메인이 있음" → `checksumlab.com` → 첫 계정 **`hello@checksumlab.com`**. 14일 무료, 이후 $7/월(연간)·$8.40/월(월별)
3. Workspace가 보여주는 TXT(소유 확인)·MX 레코드를 가비아 DNS 관리에 입력 → 10분~1시간 뒤 메일 활성
4. Google 계정 → 보안 → 2단계 인증 → 인증 앱 등록. 비밀번호 관리자(Bitwarden 무료 또는 iPhone 암호 앱)에 저장
5. 이후 모든 채널 가입 이메일 = `hello@checksumlab.com`. 유튜브 채널도 이 계정으로 (관리 콘솔 → 앱 → 추가 Google 서비스 → YouTube 켜짐 확인)
6. 주의: Workspace 해지 시 이 계정으로 만든 유튜브 채널도 소멸. 1석은 계속 유지
7. W2에 스티비 발신 도메인 인증(DKIM) 레코드도 같은 DNS에 추가
## 1. 인스타그램 (10분) — 스레드의 뿌리
스레드 계정은 인스타그램 계정으로 만들어지므로 인스타가 먼저다.
1. 인스타 앱 → 내 프로필 → 우상단 ≡ → 맨 아래 **"계정 추가" → "새 계정 만들기"** (기존 계정 로그아웃 불필요. 한 앱에 최대 5개)
2. 사용자 이름 `checksumlab` 입력 → 사용 가능 확인 (비어있음 확인됨 10/4)
3. 가입은 **이메일로**(hello@checksumlab.com). 전화번호로 하면 개인 계정과 묶여 "알 수도 있는 사람"에 노출됨
4. "연락처 동기화" "Facebook 연결" "친구 찾기" **모두 건너뛰기** — 개인 지인에게 추천 노출 방지
5. 가입 후: 프로필 → ≡ → 설정 → 계정 유형 및 도구 → **프로페셔널 계정으로 전환 → 비즈니스** → 카테고리 "미디어/뉴스 회사" 또는 "디지털 크리에이터" (금융 서비스 카테고리는 피함)
6. 설정 → 메시지 및 스토리 답장 → 메시지 요청: **"받지 않음"**, 스토리 답장 "끄기"
7. 설정 → 계정 센터 → 비밀번호 및 보안 → **2단계 인증 켜기** (인증 앱)
8. 개인 계정 전환은 프로필 상단 이름 탭 → 계정 선택. 포스트 전 **항상 어느 계정인지 확인**
