# 채널 계정 개설 가이드 — Checksum (@checksumlab)

작성 2026-10-04. 개인 계정과 완전히 분리된 "브랜드 계정" 세트를 만든다. 총 40~50분.
원칙: ① 이메일 1개로 전부 묶기 ② 핸들 전부 `checksumlab` ③ 비밀번호 관리자에 저장 ④ 2단계 인증 전부 켜기 ⑤ DM·쪽지는 끈다(양방향 소통 금지, docs/03)

## 0. 도메인 + Google Workspace (20분) — 모든 것의 뿌리
(D9: 무료 Gmail 대신 자체 도메인 메일. 이유: 뉴스레터 발신 도메인 인증(SPF/DKIM/DMARC) 필수, 스티비 발신자 @gmail.com은 스팸 위험)
1. 가비아 또는 호스팅kr에서 `checksumlab.com` 구매 (연 1.5~2만원). `checksum.kr` 비어 있으면 함께
2. workspace.google.com → 시작하기 → Business Starter → "이미 도메인이 있음" → `checksumlab.com` → 첫 계정 **`hello@checksumlab.com`**. 14일 무료, 이후 $7/월(연간)·$8.40/월(월별)
3. Workspace가 보여주는 TXT(소유 확인)·MX 레코드를 가비아 DNS 관리에 입력 → 10분~1시간 뒤 메일 활성
4. Google 계정 → 보안 → 2단계 인증 → 인증 앱 등록. 비밀번호 관리자(Bitwarden 무료 또는 iPhone 암호 앱)에 저장
5. 이후 모든 채널 가입 이메일 = `hello@checksumlab.com`. 유튜브 채널도 이 계정으로 (관리 콘솔 → 앱 → 추가 Google 서비스 → YouTube 켜짐 확인)
6. 주의: Workspace 해지 시 이 계정으로 만든 유튜브 채널도 소멸. 1석은 계속 유지
7. W2에 스티비 발신 도메인 인증(DKIM) 레코드도 같은 DNS에 추가
## 1. 인스타그램 (10분) — 스레드의 뿌리
스레드 계정은 인스타그램 계정으로 만들어지므로 인스타가 먼저다.
1. 인스타 앱 → 내 프로필 → 우상단 ≡ → 맨 아래 **"계정 추가" → "새 계정 만들기"** (기존 계정 로그아웃 불필요. 한 앱에 최대 5개)
2. 사용자 이름 `checksumlab` 입력 → 사용 가능 확인 (비어있음 확인됨 10/4)
3. 가입은 **이메일로**(hello@checksumlab.com). 전화번호로 하면 개인 계정과 묶여 "알 수도 있는 사람"에 노출됨
4. "연락처 동기화" "Facebook 연결" "친구 찾기" **모두 건너뛰기** — 개인 지인에게 추천 노출 방지
5. 가입 후: 프로필 → ≡ → 설정 → 계정 유형 및 도구 → **프로페셔널 계정으로 전환 → 비즈니스** → 카테고리 "미디어/뉴스 회사" 또는 "디지털 크리에이터" (금융 서비스 카테고리는 피함)
6. 설정 → 메시지 및 스토리 답장 → 메시지 요청: **"받지 않음"**, 스토리 답장 "끄기"
7. 설정 → 계정 센터 → 비밀번호 및 보안 → **2단계 인증 켜기** (인증 앱)
8. 개인 계정 전환은 프로필 상단 이름 탭 → 계정 선택. 포스트 전 **항상 어느 계정인지 확인**

## 2. 스레드 (3분)
1. Threads 앱 설치 → "Instagram으로 로그인" → **@checksumlab 선택** (개인 인스타 선택하지 않도록 주의)
2. 프로필 그대로 가져오기 → 핸들 @checksumlab 자동 확보
3. 설정 → 개인정보 보호 → 멘션: "내가 팔로우하는 사람", 온라인 상태 끄기
4. 설정 → 계정 → "Instagram에 공유" 자동 공유는 **끄기** (인스타는 Buffer로 카드뉴스만 재배포, 스레드 글 자동 전송 X)
5. 신규 계정 첫 주: 하루 3포스트 + 답글 5개까지만. 팔로우 몰아서 하면 제한 걸림

## 3. 유튜브 (10분)
브랜드 Gmail(0번)로 채널을 만들면 개인 Google 계정과 완전 분리된다.
1. 시크릿 창 또는 유튜브 앱에서 **hello@checksumlab.com으로 로그인**
2. 프로필 아이콘 → "채널 만들기" → 이름 **Checksum** → 핸들 **@checksumlab** 입력 (가능 여부 즉시 표시)
3. YouTube 스튜디오(studio.youtube.com) → 설정 → 채널 → 고급 설정 → "시청자층: 아동용 아님" 선택
4. 설정 → 커뮤니티 → 기본 설정 → 댓글 "검토를 위해 모든 댓글 보류" (초기엔 수동 승인 — 리딩방 홍보 댓글 차단)
5. **멤버십·슈퍼챗은 활성화하지 않음** (유료 양방향 소통 금지)
6. 맞춤설정 → 기본 정보 → 설명·링크 입력 (아래 5번 템플릿)
7. 전화번호 인증(설정 → 채널 → 기능 사용 자격요건 → 중간 기능) — 15분 초과 영상·맞춤 썸네일에 필요. 지금 해두기

## 4. X (10분)
1. X 앱 → 프로필 아이콘 → 좌하단 ⋯ 또는 "계정 추가" → **"새 계정 만들기"** (한 앱에 여러 계정 가능)
2. 가입은 **이메일로**(hello@checksumlab.com), 전화번호는 나중에 인증 요구 시 입력 (한 번호에 최대 10계정)
3. 생성 직후 자동 부여되는 랜덤 아이디를 바꿔야 한다: 설정 및 개인정보 보호 → **계정 → 계정 정보 → 사용자 아이디 → `checksumlab`**
4. 설정 → 개인정보 보호 및 안전 → 쪽지 → **"모든 사람의 메시지 요청 허용" 끄기**
5. 설정 → 보안 및 계정 접근 → 보안 → **2단계 인증 → 인증 앱**
6. 설정 → 개인정보 보호 및 안전 → 검색 가능성 및 연락처 → 이메일·전화번호로 찾기 **모두 끄기**
7. 역할: 자동 재배포 전용(D5). 직접 글 쓰지 않아도 됨. 첫 주엔 링크 포스트 금지(신규 계정 스팸 판정)
8. **유료 구독(D30)**: 10/6에 Premium으로 구독했다(행사 중, 파란 체크 발급). 사진·표시 이름·아이디를 바꾸면 파란 체크가 다시 심사될 때까지 사라지므로 한 번에 바꾸고 그 뒤로는 건드리지 않는다. 구독자 전용 글·유료 구독·후원 같은 수익화 기능은 켜지 않는다. 헤더는 `assets/brand/checksum_x_header_1500x500.png`. 근거는 decisions.md D30
