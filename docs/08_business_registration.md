# 사업자등록 → 사전교육 → 유사투자자문업 신고 가이드 (2026-10-05)

## 순서와 의존관계
```
겸업 조항 확인 ─→ 사업자등록(홈택스, 2~3일) ─┬→ 사전교육 신청·이수(kifin, 월 2회) ─→ 금감원 신고 ─→ 신고번호
                                            └→ 사업자 통장·카드 → 스티비·PG·통신판매업 신고
```
- 금감원 신고서에 **사업자등록증 사본**이 첨부서류라 사업자등록이 먼저. 사전교육은 대표자 본인 명의로 받으며 사업자등록과 병행 가능
- 무료 뉴스레터·SNS는 "투자 조언에 대한 직접적 대가성이 없으면 신고 대상 제외" → 10/20 창간은 신고 전이라도 가능. 단 "유료 예정·수익률 유인" 문구는 신고 전 영업 자료가 되므로 금지

## 0. 겸업 조항 (등록 전 필수)
- 취업규칙·고용계약의 副業/겸업 조항 확인. 일본 기업은 届出制(신고) 또는 許可制(허가)인 경우가 많음
- 허가제면 신청서 기재는 "개인 명의 정보 콘텐츠(뉴스레터) 발행업, 근무시간 외, 경업 아님" 수준으로
- 사업자등록 자체는 회사에 통보되지 않음. 노출 경로는 ① 사업소득 연 2,000만원 초과 시 건강보험 소득월액보험료(본인 주소로 고지, 회사 무관) ② 5월 종합소득세 합산(본인이 신고). 즉 법적 노출은 없고 계약상 겸업 위반 여부만 문제

## 1. 홈택스 사업자등록 (30분)
1. hometax.go.kr → 로그인(공동·금융인증서 또는 간편인증) → **신청/제출 → 사업자등록 신청(개인)**
2. 인적사항: 상호 **체크섬** (영문 병기 가능 시 Checksum). 금지어(금융투자·증권·투자자문·자산운용 등) 없음 확인됨
3. 사업장: **자택 주소**. 자가면 서류 없음, 전·월세면 임대차계약서 사본 첨부(자택을 사업장으로 쓰는 서비스업은 집주인 동의 불필요). 비상주 사무실은 §4 참고
4. 업종: 업종코드 검색창에 "유사투자자문" → 안 나오면 **"증권정보제공업" 또는 "온라인정보제공업"** 선택 후 업태/종목란에 "유사투자자문업" 직접 기재 (금감원이 사업자등록증에 이 셋 중 하나가 있으면 인정)
   - 부업종 추가: **전자상거래 소매업**(구독 결제·통신판매업 신고용). 유튜브 수익 생기면 그때 "1인 미디어 콘텐츠 창작자(940306)" 추가
5. 개업일: 신청일(10/6 시그널 기록 시작일과 맞추면 깔끔)
6. 과세유형: **간이과세** 선택 (B2C 구독, 초기 매출 소규모 → 부가세 부담 최소). 화면에서 배제 업종·지역이면 자동으로 일반과세만 표시됨. 연매출 1억 400만원 넘으면 다음 해 일반 전환
7. 제출 → 2~3일 내 세무서 처리. 담당자가 "유사투자자문업 신고했나" 물으면 "사전교육 신청, 신고 예정" 답변
8. 발급 후: 사업자등록증 PDF 저장 → `data/private/` (git 제외)

## 2. 등록 직후 할 것
- 사업자 명의 통장 1개 + 체크카드 (정산·도구비 분리. 개인사업자 사업용계좌 신고는 복식부기 의무자만이지만 처음부터 분리)
- 스티비 사업자 전환, 도메인·Workspace 영수증 사업자 명의로

## 3. 사전교육 (금융투자교육원 kifin.or.kr)
- 과정명 "유사투자자문업 신고 사전교육(실시간온라인특강포함)"
- 형식: 온라인 동영상 약 7시간 + 실시간 화상 특강 60분(카메라 필수) + 평가시험 70점. **단일 개설일 당일 24시간 내 완료**
- 개설: 월 2회. 신청 마감이 개설일 1~2주 전 → **지금 신청해야 10월 중 수강 가능**
- 수강료: 87,000원 (2023년 1기 기준, 현재가 확인)
- 유효: 수료 후 1년 이내 신고
- 대표자 본인 명의·본인인증 필수

## 4. 금감원 신고 (11월) — 미리 알아둘 것
- 첨부: 신고서, 사업계획서, 사업자등록증, 사무소 임대차계약서 또는 소유 증명, 교육 수료증, 신분증, 회원가입계약서(이용약관), 법령준수각서, 개인정보처리방침
- 결격사유: 금융 관련 법령 위반 벌금형 이상 5년 미경과, 유사투자자문업 폐지 후 1년 미경과, 신고서 허위 기재
- **처리기간이 출처마다 다름: 법률사무소 "2~4주" vs 행정사 "3~6개월"**. 2024.8 개정 후 심사 강화로 지연 사례 보고됨. → **10/6(월) 금감원 1332 또는 금융소비자포털에 현재 실제 처리기간 문의**. 2개월 이상이면 D4(12/8 기본 유료)는 못 지키므로 신고 접수를 10월 말로 당기거나 유료 오픈을 밀어야 함 → decisions.md
- 사무소 주소는 신고 수리 후 **금감원 공시·통신판매업 신고로 공개**됨. 자택 공개가 싫으면 비상주 사무실(월 3~5만원, 임대차계약서 발급)인데, 금감원이 실사무공간을 요구해 반려한 사례가 있는지 1332 문의 때 같이 확인
