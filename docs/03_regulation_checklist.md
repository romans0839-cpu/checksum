# 규제 체크리스트 — 유사투자자문업 (자본시장법 §101)

> 이 문서는 조사 기반 정리이며 법률 자문이 아님. 신고 전 금감원 유사투자자문업 안내 페이지와 최신 개정 내용을 직접 확인할 것.

## 1. 신고 전 (10월)

- [ ] 회사 취업규칙 겸업 조항 확인 → 결과: ______ (개인 / 가족 명의 / 법인 중 결정)
- [ ] 유사투자자문업 **사전교육** 이수 (금융투자교육원 온라인, 신고일 기준 1년 이내) — 이수증 보관
- [ ] 사업자등록 (업종: 유사투자자문업). 상호에 "증권·투자자문·자산운용" 등 금융회사 오인 표현 금지
- [ ] 서비스명 확정 — 위 금지 표현 제외 확인
- [ ] 통신판매업 신고 (온라인 유료 구독 판매 시)

## 2. 신고 (11월)

- [ ] 금감원 유사투자자문업 신고서 제출 (채널: 이메일 뉴스레터, 네이버 프리미엄콘텐츠, 텔레그램 채널, 유튜브 — 모든 채널명 기재)
- [ ] 신고번호 수령 → 모든 발행물·랜딩페이지에 표기
- [ ] 채널·대표자 변경 시 2주 내 변경보고 (운영 규칙에 명시)
- [ ] 유효기간 5년 → 갱신 알림 등록 (2031)

## 3. 채널 운영 규칙 (양방향 금지)

허용:
- 이메일 뉴스레터 (일방향)
- 네이버 프리미엄콘텐츠 (댓글은 콘텐츠에 대한 것으로 한정, 개별 종목 상담 답변 금지)
- 텔레그램 **채널** (댓글/토론 기능 OFF)
- 유튜브 업로드

금지 (투자자문업 등록 없이는 불가):
- 카카오 오픈채팅, 텔레그램 **그룹**, 디스코드 채팅
- 1:1 상담, DM으로 개별 포트폴리오 조언
- 구독자 자산 상황을 묻고 맞춤 답변

운영 원칙: 구독자 질문에는 "개별 상담 불가, 일반적 내용은 다음 호에서 다룸"으로 정형 응답.

## 4. 발행물 문구 규칙 (부당광고 방지)

금지:
- "목표수익률 OO%", "월 OO% 수익", 종목별 수익률 단순 합산 표기
- "원금보장", "확실한", "무조건", "손실 없는"
- 실계좌 수익률 캡처 공개 (D3 결정: 실계좌는 비공개)
- 특정 증권사·금융기관 제휴 오인 표현

필수:
- 모든 발행물 하단 disclaimer (templates/disclaimer.md) 자동 삽입
- "투자 판단은 본인 책임, 원금 손실 가능" 문구
- 유사투자자문업 신고번호
- 시그널 통계 공개 시: 표본수·기간·산출 방식·수수료/슬리피지 반영 여부 함께 표기

파이프라인 반영: pipeline/publish/lint.py 에서 금지어 검출 시 발행 차단.

## 5. 환불·계약

- 월 구독, 언제든 해지, 첫 결제 후 7일 이내 전액 환불 (전자상거래법 청약철회 준수)
- 연간 선납 상품은 초기에 만들지 않음 (리딩방 민원 1위가 환불분쟁)
- 이용약관·개인정보처리방침 게시

## 6. 일본 확장 시 (2단계)

- 월정액 종목추천은 投資助言業 등록 필요 (보증금 500만엔, 국내 영업소·대표자)
- 등록 없이 가능한 범위: 단발 판매 교육 콘텐츠, 추천 없는 데이터·통계 제공
- 옵션: 등록 투자고문(예: 근기재무국 등록 업체)과 콘텐츠 제휴

## 7. 이해상충 — 운영자가 시그널 종목을 보유·매매하는 경우 (2026-10-05 추가, D11)

판례: 선행매수 사실과 "추천 후 매도할 수 있다"는 이해관계를 표시하지 않은 추천은 부정거래(대법원 2022.5.26. 2018도13864). 과거에 보유를 말했다는 것만으로는 부족(2025.12.11. 2025도4748). 제3자 선행매수·비금전 이익도 포함(2026.1.15. 2024도11686).

- [ ] 모든 시그널·결산·지연 공개에 보유·매도 가능 고지 (templates/disclaimer.md)
- [ ] 구독자 선발송: 발행 시각 ≤ 운영자 주문 시각, 두 시각을 장부에 기록 (금액·수량 기록 금지 — D3)
- [ ] 청산 시그널도 운영자 매도 전 또는 동시 발행
- [ ] 유동성 하한·프로 정원 산정
- [ ] 시그널 종목 재량 매매 금지
- [ ] 변호사 1회 확인 (문구·무료 지연 공개의 추천 해당 여부)

## 8. 광고·표현 추가 주의 (2026-10-05 추가)

- 개정 시행령 금지 광고: 허위 또는 미실현 수익률 제시, 특정 기간 우수 실적만 선택 표시, 불확실한 사항에 대한 단정적 판단. → 열린 포지션 손익 표시 금지, 백테스트 수치는 서비스 성과 광고에 쓰지 않음
- "검증된 시그널" 표현 금지 (D12). 라이브 시스템의 지위는 '1차 필터 통과, 최종 판정은 라이브 계측' — banned_terms.txt 반영
- 자동매매 프로그램 판매·대여·주문 연동은 미등록 투자일임으로 적발된 유형 → 제안·제공하지 않음
