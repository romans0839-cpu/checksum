# 마케팅 전략 — 개인사업자, 광고비 0, SNS 풀활용 (2026-10-04)

전제: 광고 예산 없음. 쓸 수 있는 건 시간·자동화·트랙레코드. 목표는 2027-09 무료 구독자 8,000명(베이스 시나리오).
조사 요약은 §7, 원 출처는 하단.

## 1. 한 문장 전략

**스레드(Threads)로 매일 발견되고, 유튜브로 신뢰를 쌓고, 뉴스레터로 소유한다.** 다른 채널은 자동 재배포로만 운영한다.

이유: 스레드는 2026.7 MAU 798만·성장률 1위, 2030 중심, 알고리즘이 신규 계정에 가장 열려 있음(인스타 10년 700 팔로워 vs 스레드 6개월 1만 팔로워 사례). 유튜브는 서학개미 최대 정보원이지만 0에서 성장이 느려 "검증 콘텐츠 보관소" 역할. 뉴스레터는 플랫폼 종속 없는 유일한 자산.

## 2. 채널 역할 분담

| 채널 | 역할 | 투입 | 운영 방식 |
|---|---|---|---|
| **스레드** | 1차 발견·유입 | 하루 40분 | 하루 3개 포스트(06:30 마감 요약 / 12:00 데이터 1장 / 21:00 질문형) + 타인 글 실질 답글 5개. 수동 — 알고리즘이 대화를 봄. (2026-10-06: "21:00 질문형"은 말투 지침 §3의 "질문으로 끝내며 반응을 끌어내는 문장"과 부딪힌다. 첫 2주 초안은 21:00을 만드는 중·장부·일정으로 채웠고, 06:30은 트렌디 체크다 — `data/sns/drafts/2026-10-09_first_two_weeks.md`) |

| **인스타** | 자동 재배포 | 0 (자동) | 카드뉴스 Canva 벌크 → Buffer 예약. 릴스는 쇼츠 재업로드 |

| **텔레그램** | 프로 주간 발행 알림 전용 | 자동 | 댓글 잠금 채널. 마케팅 채널로 쓰지 않음(리딩방 연상) |
| 토스증권 커뮤니티 | 관찰만 | 주 1회 | 2030 서학개미 피드. 어떤 종목·질문이 뜨는지 콘텐츠 소재 발굴. 링크 유도 불가 |

하루 총 투입 목표: **평일 90분**(스레드 40 + 검수 30 + 답글·관찰 20), 주말 유튜브 3시간.

## 3. 콘텐츠 기둥 (4개, 반복 — 전체 편성은 docs/09 §5)

> 2026-10-05 D21: 줄기·채널 편성의 기준은 **docs/14**다. 재미있는 뉴스 코너 "트렌디 체크"(SNS 하루 1건)와 엔진 줄기(발표 다음 날 "두 엔진과 실제" 한 장)가 더해졌고, 메신저는 텔레그램 일방향 채널을 11월에 연다. 아래 기둥은 그 안에서 계속 쓴다.

1. **"오늘 미국장 3줄"** — 매일 아침. 가장 빠르고 가장 짧게. 스레드·뉴스레터 공통 리드
2. **"화요일 본편"** — 주 1회. 주도 업종 지도·Top 50 위험 신호등·레짐 계기판에서 숫자 1장. (2026-10-05 D12로 변경 — 라이브 봇은 월 진입 약 1.9건이라 "주간 시그널 결산"은 기둥이 될 수 없음. 장부 지연 공개는 금요일 레터에 0건이면 0건 그대로)
3. **"통념 체크"** — 주 1회. 서학개미 통념 하나를 25년 데이터로 가려낸다(원재료: 폐기·기각한 실험 126개). 리딩방 수익률 캡처 읽는 법도 이 기둥. 분기마다 "분기 심판"(봇 분기 리뷰 공개)이 유튜브 롱폼의 기둥. 교육이자 포지셔닝("우리는 반대편")
4. **"글로벌 체크"** — 주 1회 + 월 1회 확장판. 세계 경제·금리·환율을 무슨 일 / 서학개미에게 닿는 길 / 시장이 이미 알던 것 / 아직 모르는 것으로. 분기마다 "전망 체크"(전망이 맞았는지 채점). 공공 1차 출처라 라이선스 부담 없음 (2026-10-05 D14)

금지: 종목 추천 톤, 수익률 자랑, 시황 예측. 이 셋은 리딩방 콘텐츠 기둥이고 규제 리스크의 전부다.

## 4. 퍼널과 전환 장치

```
스레드/유튜브 노출 → 프로필 링크(랜딩) → 무료 뉴스레터 구독
  → 웰컴 3통(자동): ①우리가 다른 이유 ②시그널 통계 읽는 법 ③지난 결산 샘플
  → 매주 "결산" 수신 → 12월 기본 티어 오픈 안내 → 프로 대기자 등록
```

- 스레드 프로필 링크는 하나만: 랜딩페이지. 랜딩은 구독 폼 + 통계 위젯 + 3줄 설명
- 모든 스레드 포스트는 링크 없이 발행(노출 페널티), 셀프 답글에만 링크
- 쇼츠 설명·고정댓글 → 롱폼 → 롱폼 설명 → 뉴스레터. 쇼츠 단독 전환은 기대하지 않음
- 전환 시작점은 **팔로워 3,000~5,000** (스레드 사례). 그 전엔 전환율 보지 말고 참여율(30%+)만 봄

## 7. 규제 — 마케팅에서 특히 조심할 것

- 모든 채널 프로필·영상 설명·뉴스레터에 **상호 + 유사투자자문업 신고번호** 표기 (2026.4 금감원 AI 모니터링 가동, 유튜브 금융채널 5곳 중 4곳 미신고 적발)
- **통신판매업 신고 + 사업자 정보 표기** (소비자원 2025.12: 유료 유튜브 투자채널 45.5% 미신고 지적)
- 유료 멤버십 댓글·DM 상담·오픈채팅 = 양방향 → 금지. 유튜브 멤버십은 켜지 않음
- 수익률을 "달성 가능"처럼 쓰는 모든 표현 금지. 시그널 결산은 항상 표본수·기간·슬리피지 명시
- AI 생성 페르소나가 투자 조언하는 영상은 유튜브 수익화 불가 → 얼굴 또는 실명 목소리 1개는 필요

## 8. 조사 요약 (근거)

- 2030 서학개미 정보원: 유튜브 데일리 요약 영상 > 토스증권 커뮤니티(월 400만) · 네이버 종목토론 · X. 증권사 유튜브 200~300만 구독이 콘텐츠 기준선
- 스레드 KR: MAU 2024.10 648만 → 2026.7 798만, 100만+ SNS 중 성장률 1위. 월 체류 3.5h(인스타 21.5h) → 짧고 잦은 글. 2026 알고리즘 "대화 우선"(답글·완독). 발행 후 30~60분 반응이 노출 결정
- 성장 공식(스레드 사례): 트래픽:전문성:개성 = 1:6:3, 참여율 30~40%, 팔로워 3천부터 매출 발생. 90일 가이드: 1~30일 다수 포스팅, 31~60일 섹터 고정·정형화, 60일 후 J커브
- 뉴스레터: 미국주식 레터 표준은 평일 오전 8시 전후 데일리. 스티비 2025: 자동화 메일 오픈 1.6배·클릭 3.8배. beehiiv 2026 글로벌: 신규 레터 중위 첫 달 482명 → 1년 8,314명, 첫 매출 중위 66일
- 쇼츠는 유입·롱폼은 전환. 릴스 10만 뷰 → 팔로워 약 1.5%
- 기존 플레이어: 머니네버슬립(데일리 레터 → 증권사 B2B 공급이 핵심 수익), 순살브리핑(레터+카드뉴스+유료 강의, 외부 투자 없음) — **둘 다 "시그널·검증" 축은 없음**
