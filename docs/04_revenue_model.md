# 수익 모델

계산: `python scripts/revenue_sim.py` (시나리오·가정 수정은 스크립트 상단).

## 가정

| 항목 | 베어 | 베이스 | 불 |
|---|---|---|---|
| 무료 구독자 월 순증 | 250~300 | 400 → 900 | 600 → 2,600 |
| 기본 티어 전환율 (월, 검토풀 대비) | 2% | 3% | 4% |
| 프로 티어 전환율 | 0.6% | 1% | 1.5% |
| 월 이탈률 | 10% | 8% | 6% |

공통: 기본 15,000원 / 프로 59,000원 (VAT 포함), 플랫폼 수수료 10.4%, 고정비 월 25만원, 유료 오픈 12월, 프로 오픈 1월.

"검토풀" = 당월 신규 무료 구독자 + 기존 무료 풀의 1/6 (매월 일부가 유료 전환을 검토한다고 가정).

## 해석

- 프로 티어가 유료 구독자의 24%지만 매출의 56% → **프로 티어 신뢰(트랙레코드)가 수익의 핵심**
- 무료 구독자 유입이 가장 민감한 변수. 전환율 1%p보다 유입 200명/월이 더 큼
- 손익분기(고정비 회수)는 12월 즉시. 시간 투입 대비 의미 있는 수준(월 300만+)은 2027년 3월
- 월 1천만원 목표 = ~~유료 400명 수준 = 무료 8천명 풀~~ → 2026-10-10 코드로 다시 냄: **유료 492명(기본 371 · 프로 121) · 무료 8,800명, 2027-11(13개월차)**. 프로가 유료의 10%쯤이면 유료 649명 · 2028-03, 기본만이면 839명 · 2028-07. 가격 적정성과 광고 수주 검토는 `docs/19_pricing_and_ads_review.md`(계산 `python scripts/pricing_review.py`) → 유튜브·네이버 검색 유입 없이는 도달 어려움

## 검증할 지표 (MVP 기간)

- 무료 오픈율 ≥ 45%, 클릭률 ≥ 8%
- 무료→유료 대기자 등록률 ≥ 5%
- 위 미달 시 콘텐츠 형식(길이·발행시간·주제)부터 A/B

## 목표 경로 (D10) — 2026-10-05 추가

목표: 3년 내(~2029-10) 월 순수익 5,000만원, 5년 내(~2031-10) 1억원. 계산: `python scripts/path_to_100m.py` (위 모델을 60개월로 연장, 13개월차 이후 무료 유입이 2개월마다 +100명씩 계속 늘어난다고 가정).
순수익 = 총매출 ÷ 1.1 × (1 − 수수료 10.4%) − 고정비 25만. 필요 총매출: 5,000만 → 6,169만 / 1억 → 1억 2,307만. 유료 구독자로는 프로 비중 24%에서 약 2,414명 / 4,815명.

| 시나리오 | 36개월차 순수익 | 60개월차 순수익 | 5천만 도달 | 1억 도달 |
|---|---|---|---|---|
| 베이스 (이탈 8%, 유입 계속 가속) | 6,394만 | 1억 6,894만 | 2029-06 | 2030-08 |
| 이탈 16.67% (금융 유료 레터 벤치마크) | 3,945만 | 9,637만 | 2030-04 | 미도달 |
| 유입이 1년차 뒤 월 900명에서 정체 | 4,343만 | 8,109만 | 2030-03 | 미도달 |
| 프로 전환 0.5% | 4,574만 | 1억 2,095만 | 2029-12 | 2031-05 |
| 프로 전환 0.5% + 기본 전환 5% | 6,426만 | 1억 6,975만 | 2029-06 | 2030-08 |
| 위 + 이탈 5% | 8,030만 | 2억 2,600만 | 2029-03 | 2030-03 |

- 베이스가 맞으려면 무료 구독자 3년 45,000명·5년 111,000명, 월 이탈 8%가 유지돼야 한다. 깨지는 지점은 이탈과 유입 둘.
- 미반영: 소득세, 데이터 표시 라이선스 비용(공개된 범위 월 $399~$2,499, docs/10), LLM 호출 비용, 유료 오픈 지연(사전교육 12/17 회차로 밀릴 경우 1월 — plan/status.md). 확정되면 스크립트의 고정비·시작 월을 고치고 이 표를 다시 낸다.
- 사업자는 일반과세(D16). 위 식은 처음부터 부가세 10%를 뺀 값이라 영향 없음.
